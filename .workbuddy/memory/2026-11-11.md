## 修复 Unity 6.5 (6000.5.9f1) 升级导致的 CS0619 编译错误（InstanceID → EntityId 迁移）

项目从旧版 Unity 升级到 6000.5.9f1 后，控制台出现 660 条 `error CS0619`，全部是 InstanceID 体系 API 被 EntityId 体系取代并标记为 error。

### 迁移规则（关键，后续升级还会遇到）
- `Object.GetInstanceID()` → `Object.GetEntityId()`，返回 `UnityEngine.EntityId`（8 字节结构体，无法用 int 表示）。
- **`EntityId` 与 `int` 的隐式/显式转换在 6.5 已被标记为 error（移除中）**，不能依赖 int↔EntityId 转换。
- 取原始 ulong：`EntityId.ToULong(EntityId)` 是**静态**方法（无实例形式 `entityId.ToULong()`）。取 int 用 `(int)EntityId.ToULong(obj.GetEntityId())`（截断为会话内唯一的 index）。
- `EntityId` 静态属性 `None`；实例方法 `Equals`/`GetHashCode`/`ToString`/`IsValid`/`CompareTo`；有 `==`/`!=` 运算符。
- `EditorUtility.InstanceIDToObject(int)` → `EditorUtility.EntityIdToObject(EntityId)`。
- `EditorApplication.hierarchyWindowItemOnGUI` → `hierarchyWindowItemByEntityIdOnGUI`，回调签名 `int` → `EntityId`。
- `DragAndDrop.HierarchyDropHandler` → 已移除，用 `HierarchyDropHandlerV2(EntityId, ...)`。
- `TreeView`/`TreeViewItem`/`TreeViewState` → 泛型 `TreeView<int>` 等。**用 using 别名**（`using TreeView = UnityEditor.IMGUI.Controls.TreeView<int>;`）改动最小，嵌套类型 `RowGUIArgs` 等通过基类继承仍可用简单名。

### 修复范围
- 第一波（当前控制台报错的 9 个程序集）：ToonyColorsPro、Cinemachine、UnityGameFramework.Editor、spine-unity、ParadoxNotion(NodeCanvas)、Coffee.UIParticle、UniFramework(UniTween/UniLocalization)、UniTask。
- 第二波（依赖程序集里尚未编译到、会随修复浮现）：Timing.cs(MEC)、AtlasLoader、Coffee UIEffect、PrefabBinderTool、Spine Editor 脚本、Cinemachine Editor、TCP2 Editor、AssetDanshari。

### 经验
- 升级 Unity 6.5 报 CS0619 时，日志里只显示"根因程序集"的错误，依赖程序集的错误会被跳过隐藏，需修复后多轮重编译才会全部浮现。用 `grep -oE "error CS[0-9]+"` 统计 + 全项目 grep 废弃 API 定位所有受影响文件。

## 修复 TMP 文字不显示 / 反复弹 TMP Importer

### 根因
TMP 找配置只认一个固定路径：`Resources.Load<TMP_Settings>("TMP Settings")`，即**任意 Resources 根目录下的 `TMP Settings.asset`**。
本项目把它放在了 `Assets/Resources/TMP/TMP Settings.asset`（**多了一层 TMP 目录**），所以：
- 编辑器里 TMP 认为 Essentials 没导入 → 反复弹 TMP Importer 窗口
- 运行时 `TMP_Settings.instance == null` → TMP 文本初始化不完整 → **文字不显示**，并伴随 `TextMeshProUGUI.Cull` 空引用（就是上面那条 NRE）

另外：我在重写流程时把 `TMPHelper.LoadSettingsDefault()`（用反射注入 `s_Instance` 的兜底）漏掉了，双重原因。

### 修复
1. `git mv Assets/Resources/TMP/TMP Settings.asset → Assets/Resources/TMP Settings.asset`（保留 guid）
2. `TMPHelper.TmpSettingsResourcesPath` 改成 `"TMP Settings"`
3. `GameFlow.BootRoutine` 第 1.5 步加回 `TMPHelper.LoadSettingsDefault()`，必须在打开任何界面前

### 验证
```
TMP Settings = TMP Settings            ← 原生查到了
Text chars=4 meshVerts=16 font=BalooPaaji2-ExtraBold SDF shader=TextMeshPro/Distance Field
```
顶点数 > 0 = 文字真的画出来了。控制台 0 error / 0 warning（那条 TMP NRE 也消失了）。

### 注意
**不要再去点 Import TMP Essentials**。它会把官方包导入 `Assets/TextMesh Pro/Resources/`，产生第二个 `TMP Settings.asset`，
和 `Assets/Resources/TMP Settings.asset` 形成同名冲突（Resources.Load 结果不确定），会把这个问题再引回来。
本项目 TMP 的 shader 在 `Assets/ThirdParty/TextMesh Pro/Shaders`，字体在 `Assets/RawAsset/Fonts`，都在，不需要再导。
